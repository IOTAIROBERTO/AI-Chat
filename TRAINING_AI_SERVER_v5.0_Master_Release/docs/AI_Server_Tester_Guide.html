01

What the tester is and how to open it

The AI Server Tester is a browser-based debug panel that lets you connect to the RAG server and test it interactively — send text and voice queries, check which manuals are indexed, monitor real-time server health, and read timestamped debug logs.

It is a standalone HTML file. No installation required. Open it in any modern browser on any device that is on the same network as the server PC.

Two ways to open it

MethodHowBest for
A — Open the file directly Double-click AI_Server_Tester.html in File Explorer. Works on Windows, Mac, or Android. Local PC testing, quick checks
B — Open via the server URL With the server running, open https://<SERVER-IP>:5000/admin in any browser. Meta Quest, phones, other devices on the network — no file transfer needed
ℹ️
Method B is recommended for Meta Quest. Open the Quest browser, type the server address with /admin at the end (e.g. https://192.168.1.50:5000/admin) and accept the certificate warning once.
⚠️
The server must be running before you can connect. Start it via the launcher (start_server.bat) or the GUI, then wait for the green "Running" indicator before opening the tester.

03

Connection panel — connect to the server

⚡ Conexión
HTTPS 192.168.1.50 5000
CONECTAR / VERIFICAR

Fields and controls

ControlWhat to enter / do
Protocol button
HTTPS / HTTP		 Click to toggle between HTTPS and HTTP. Leave on HTTPS (green) unless the server explicitly uses HTTP. The server uses HTTPS by default for Meta Quest compatibility.
IP address field Enter the local IP of the server PC — not localhost unless the tester is running on the same machine as the server.
Find the IP with: ipconfig | findstr IPv4 in CMD on the server PC.
Port field Leave as 5000 unless the server was started on a different port.
CONECTAR / VERIFICAR Runs a health check against /health. Populates the status panel and loads the manual list if the connection succeeds.

SSL certificate warning — how to accept it

The server uses a self-signed certificate. Browsers block HTTPS connections to self-signed certs by default. If the connection fails, a yellow banner appears:

⚠ Certificado SSL no confiable.
1. Abre https://192.168.1.50:5000/health en una nueva pestaña
2. Acepta el certificado (Avanzado → Continuar)
3. Vuelve aquí y presiona CONECTAR
1

Click the link in the yellow banner

It opens https://<IP>:5000/health in a new tab. The browser shows a security warning page.

2

Accept the certificate

Click Advanced → Proceed to [IP address] (unsafe). You should see a JSON response like {"status":"healthy",...}. That tab can be closed.

3

Come back and click CONECTAR / VERIFICAR

The connection should now succeed. The header dot turns green. You only need to do this once per browser per session.

✅ Connection confirmed when:

The dot in the header bar turns solid green · Status text shows the IP and response time (e.g. 192.168.1.50:5000 — 42ms) · The server status panel fills with data.

This panel lists every PDF that has been indexed into the RAG database. It loads automatically when you connect and can be refreshed with the ↺ button.

ColumnMeaning
Manual name (blue)The filename of the PDF without the .pdf extension. This is also the name used to filter queries to a specific document.
chunksNumber of text segments extracted from this PDF. More chunks = more content searchable by the RAG engine.
pgsNumber of pages in the original PDF that contained extractable text.
ℹ️
If the panel shows "No hay manuales indexados", no PDFs have been uploaded yet. Use the launcher GUI to index a PDF first, then refresh this panel.
06

Text query — ask a question by typing

🔍 Consulta
✏ TEXTO
🎤 AUDIO
¿Cuál es el procedimiento de reinicio del motor?
ENVIAR CONSULTA
1

Make sure you are connected

The header dot must be green. If not, click CONECTAR / VERIFICAR first.

2

Select the TEXT tab

Click ✏ TEXTO in the tab row. It highlights in cyan when active.

3

Type your question

Click the text field (highlighted with a cyan left border) and type your question in Spanish or English. The server auto-detects language from the prompt.

Examples: ¿Cómo reiniciar el sistema de refrigeración? · What is the maximum operating pressure?

4

Send — button or Enter key

Click ENVIAR CONSULTA or press Enter. The request timer starts immediately.

5

Read the answer

The response box fills with the answer, timing badges, model used, and source references. See Section 08 for how to read it.

💡
Tip — ask in the language of the manual. If the PDF is in Spanish, ask in Spanish. The RAG retrieval is more accurate when the query language matches the document language. Both languages are fully supported.
07

Audio query — ask a question by voice

🔍 Consulta
✏ TEXTO
🎤 AUDIO
🎤   MANTENER PARA HABLAR
Grabación: 0s Tamaño: 0 KB Formato: webm/opus Enviado como: WAV 16kHz mono

The audio pipeline: Record → Convert to WAV → STT (Whisper) → RAG retrieval → LLM answer. The tester handles everything automatically.

1

Select the AUDIO tab

Click 🎤 AUDIO. The hold-to-record button appears.

2

Grant microphone permission (first time only)

The browser asks for microphone access when you first press the button. Click Allow. The status bar shows "Micrófono listo" when granted.

3

Hold the button and speak

Press and hold the 🎤 MANTENER PARA HABLAR button (mouse click or touch on Quest). The button turns green and shows ⏺ GRABANDO... with a live duration counter. Speak your question clearly.

4

Release to send

Release the button. The audio is automatically converted to 16 kHz mono WAV and sent to the server. The request timer starts. The full pipeline (STT + RAG + LLM) typically takes 5–20 seconds.

5

Check the transcription and answer

The response box shows what Whisper heard (Pregunta) and the AI answer. If the transcription is wrong, speak more slowly and clearly or move closer to the microphone.

Audio stat shownWhat it means
GrabaciónRecording duration in seconds
TamañoRaw audio blob size before conversion
FormatoFormat captured by the browser (webm/opus, ogg, or wav depending on the browser)
Enviado comoAlways WAV 16kHz mono — the tester converts the audio before sending, which is what Whisper expects
⚠️
Whisper STT must be loaded. Check the Server Status panel — Whisper STT must show Cargado ✓. On the very first audio query the Whisper model downloads (~769 MB) and the request will take longer.

Common errors and fixes

🔴Connection fails immediately — yellow cert banner appears

Cause: The browser blocks HTTPS connections to self-signed certificates by default.

Fix: Follow the three steps in Section 03 — open the /health link from the banner in a new tab, accept the certificate, then reconnect.

🔴Connection fails — no banner, console shows "fetch failed" or timeout

Cause A: Wrong IP address — you entered localhost but the tester is on a different device.

Fix A: Find the server PC's IP with ipconfig | findstr IPv4 and enter that IP.

Cause B: The server is not running.

Fix B: Open the launcher on the server PC and click ▶ Start Server. Wait for the green indicator before connecting.

Cause C: Firewall is blocking port 5000.

Fix C: Run this on the server PC as Administrator:

netsh advfirewall firewall add rule name="TRAINING AI SERVER" dir=in action=allow protocol=TCP localport=5000-5010 profile=any
🔴Server status shows — Modelo LLM: blank or red

Cause: No Ollama model is installed, or the configured model was deleted.

Fix: Open the launcher → Download section → select phi4-mini → click Download. The server restarts automatically after the download completes.

🔴Query returns — "No encontré información relevante en los manuales"

Cause: No PDFs have been indexed, or the query does not match anything in the indexed content.

Fix A: Check the Indexed manuals panel — if empty, index a PDF via the launcher first.

Fix B: Rephrase the question using keywords that appear in the document. The RAG retrieval is keyword-sensitive; exact terminology from the manual gives better results.

🟡Whisper STT shows "No cargado" — audio tab disabled effectively

Cause A: Whisper model is still downloading on first use (~769 MB). Wait and refresh the health check.

Cause B: Whisper failed to initialize (Python package issue or missing CUDA DLL).

Fix: Check the server console log at %APPDATA%\..\Local\TRAINING AI SERVER\logs\server_console.log for the specific error. Text queries still work while Whisper is unavailable.

🟡Audio query transcribes wrong words or in the wrong language

Cause: Background noise, low microphone volume, or speaking too fast.

Tips:

  • Speak clearly and at a moderate pace.
  • Hold the microphone closer to your mouth (especially on Meta Quest).
  • Reduce background noise — fans, air conditioning, other voices.
  • Check the Idioma badge in the response — if it shows the wrong language, Whisper auto-detected incorrectly. Switch to text mode for better control.
🟡Audio query takes very long (> 30 s) or times out

Cause A: First-ever audio query — Whisper model is being downloaded in the background. Let it finish (progress visible in server console).

Cause B: Server is running on CPU with a large Whisper model. medium Whisper on CPU takes 5–15 seconds for transcription depending on recording length.

Fix: Keep audio queries under 15 seconds of speech. For longer questions, use text mode.

🟡Microphone permission denied — browser blocked access

Cause: Browser microphone permission was denied previously.

Fix — Chrome / Edge: Click the lock icon in the address bar → Site settings → Microphone → Allow. Reload the page.

Fix — Meta Quest browser: Settings → Privacy → Microphone → Allow for this site.
