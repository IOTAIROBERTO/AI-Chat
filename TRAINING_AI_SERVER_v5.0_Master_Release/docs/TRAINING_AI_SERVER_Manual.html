02

Python version — which one and why

Not all Python versions work with this server. Read this before installing anything.

Python versionStatusWhy
3.13 ⭐ Recommended ✅ Works Most packages have precompiled wheels for 3.13. Requires one special install step for av (explained in Step 6).
3.12 ✅ Works Fully compatible, no workarounds needed. Slightly older but all packages install normally.
3.11 ✅ Works Fully compatible, simplest install — oldest supported version. All wheels precompiled.
3.14 ❌ Does NOT work tokenizers (used by ChromaDB) uses Rust bindings (PyO3). PyO3 v0.22.5 only supports up to Python 3.13. Python 3.14 will fail with a Rust compilation error.
3.10 or older ❌ Not supported Too old — several packages require at least Python 3.11.
🔴
Important: If you have Python 3.14 installed, it will not work. You must install Python 3.13 and use it explicitly with the py -3.13 command throughout this guide.
ℹ️
If you already have Python installed — that's fine. You can have multiple Python versions on the same machine. This guide always uses py -3.13 to make sure the right version is used, even if 3.14 is also installed.
03

Step 1 · Install Python 3.13

Open CMD or PowerShell as Administrator and run one of the following methods.

Method A — Automatic (recommended, Windows 10/11)

Uses winget, the built-in Windows package manager. No downloads needed.

CMD or PowerShell — Administrator
winget install Python.Python.3.13 -e --accept-source-agreements --accept-package-agreements

Method B — Manual download (if winget doesn't work)

Download the installer from python.org/downloads and run:

CMD — Administrator
# After downloading python-3.13.x-amd64.exe, run:
python-3.13.x-amd64.exe /quiet InstallAllUsers=0 PrependPath=1 Include_test=0

Replace x with the actual version number (e.g. python-3.13.3-amd64.exe).

✅ Verify — open a NEW CMD window and run:
CMD
py --list

You should see -3.13-64 in the list. Also check:

CMD
py -3.13 --version

Expected output: Python 3.13.x

⚠️
Always open a new CMD window after installing Python. The old window won't have the updated PATH and won't find the new Python.

If py --list shows Python 3.14 as default

That's fine — you will use py -3.13 throughout this guide to target Python 3.13 explicitly. The 3.14 installation won't interfere.

04

Step 2 · Install Ollama

Ollama is the engine that runs the AI models locally on your machine.

Method A — Automatic (recommended)

CMD or PowerShell — Administrator
winget install Ollama.Ollama --accept-source-agreements --accept-package-agreements

Method B — Manual download

Download OllamaSetup.exe from ollama.com/download, then:

CMD — Administrator
OllamaSetup.exe /S
✅ Verify — open a NEW CMD window and run:
CMD
ollama list

Expected: an empty table (no models yet) or a list if models are already downloaded. Any response without an error means Ollama is installed and running correctly.

ℹ️
Ollama starts automatically as a background service after installation. You do NOT need to run ollama serve. If you try to run it and get a "port already in use" error, that just means Ollama is already running — which is correct.
⚠️
If ollama is not recognized even after install, the PATH was not updated. Fix: close CMD, open a new one as Admin, then run:
setx PATH "%PATH%;%LOCALAPPDATA%\Programs\Ollama" /M
Then open a NEW CMD window again.
05

Step 3 · Set environment variables

Environment variables tell programs where to store files and how to behave. Set these once — they persist permanently.

ℹ️
What is an environment variable? It's a named setting stored in Windows that programs can read. For example, ANONYMIZED_TELEMETRY=False tells ChromaDB to stop sending usage data and stops a recurring warning in the server logs.

Set all required variables

CMD — Administrator
# Disable ChromaDB telemetry (stops a recurring warning in logs)
setx ANONYMIZED_TELEMETRY False /M

# Optional: move Ollama models to a different drive (e.g. D:\ to save space on C:\)
# Only set this if you want models on a different drive. Otherwise skip it.
# setx OLLAMA_MODELS "D:\ollama-models" /M
⚠️
After running setx, you MUST open a NEW CMD window. The current window does not reload environment variables.
✅ Verify — in a new CMD window:
CMD
echo %ANONYMIZED_TELEMETRY%

Expected output: False

Step 6 · Install Python packages

This step installs all the libraries the server needs (Flask, ChromaDB, Whisper, etc.).

The installation process is slightly different depending on your Python version. Follow the section that matches what you installed in Step 1.

— Python 3.11 or 3.12 — Simple install

All packages have precompiled files for these versions. One command does everything.

CMD
# First, upgrade pip
py -3.12 -m pip install --upgrade pip

# Then install everything
py -3.12 -m pip install -r "C:\AI-Server\server\requirements.txt"

Replace -3.12 with -3.11 if you installed 3.11.

— Python 3.13 — Special install order

🔴
Do not run pip install -r requirements.txt directly on Python 3.13.
The package faster-whisper requires av<13 in its settings, but av<13 has no ready-to-use file for Python 3.13 on Windows — pip would try to compile it from source code, which requires FFmpeg development files that are not installed. Follow the 4 steps below instead.
1

Upgrade pip first

CMD
py -3.13 -m pip install --upgrade pip
2

Install av — the Python 3.13 compatible version

This is the audio processing library. Version 13+ has a ready-to-use file for Python 3.13; older versions do not.

CMD
py -3.13 -m pip install "av>=13.0.0"
3

Install faster-whisper without its dependency check

The flag --no-deps tells pip to install the package without checking its version requirements for other packages. This lets us keep av≥13 installed. The package works correctly at runtime.

CMD
py -3.13 -m pip install faster-whisper==1.1.1 --no-deps

Then install the extra libraries faster-whisper needs:

CMD
py -3.13 -m pip install ctranslate2 "huggingface_hub>=0.13" tokenizers
4

Install all remaining packages

CMD
py -3.13 -m pip install flask==3.1.0 flask-cors==5.0.0 ollama==0.4.4 ^
    chromadb==0.5.23 PyPDF2==3.0.1 colorama==0.4.6 ^
    requests==2.32.3 "cryptography>=45.0.1"
✅ Verify — check that the main packages are installed:
CMD
py -3.13 -m pip show flask chromadb faster-whisper ollama

Each package should show its name and version. If any of them shows "WARNING: Package(s) not found", re-run that specific install command.

✅
It's normal to see a warning about cryptography 45.0.0 yanked. The command above installs 45.0.1 or later which fixes it. You may also see ChromaDB telemetry warnings — those are silenced by the environment variable set in Step 3.

Step 7 · Create server configuration file

This file tells the server which AI model to use and what language settings to apply. It will be created automatically on first run, but creating it now lets you set the correct model from the start.

CMD
(
echo {
echo   "current_model": "qwen3:1.7b",
echo   "bilingual_mode": true,
echo   "primary_language": "es",
echo   "supported_languages": ["es", "en"]
echo }
) > "C:\AI-Server\server\server_config.json"

The server starts with qwen3:1.7b (always installed). To upgrade to phi4-mini for better Q&A quality, download it from the launcher, then change "current_model" to "phi4-mini" and restart.

✅ Verify:
CMD
type "C:\AI-Server\server\server_config.json"

You should see the JSON content printed on screen.

Step 8 · Configure firewall

The server listens on port 5000. For other devices (Meta Quest, phones, other computers on your network) to reach it, Windows Firewall must allow connections on that port.

Open port 5000

CMD — Administrator
netsh advfirewall firewall add rule ^
  name="TRAINING AI SERVER" ^
  dir=in action=allow protocol=TCP ^
  localport=5000-5010 profile=any

Add Windows Defender exclusions

This prevents Defender from slowing down ChromaDB and Whisper by scanning their files on every access.

PowerShell — Administrator
Add-MpPreference -ExclusionPath "C:\AI-Server"
Add-MpPreference -ExclusionProcess "python.exe"
Add-MpPreference -ExclusionProcess "ollama.exe"
✅ Verify — check the firewall rule was created:
CMD
netsh advfirewall firewall show rule name="TRAINING AI SERVER"

You should see the rule listed with Action: Allow.

Step 9 · Launch the server

Option A — Double-click launcher (recommended)

Open File Explorer → navigate to C:\AI-Server\ → double-click launch_server.bat.

launch_server.bat uses pythonw.exe — the GUI opens instantly with no console window. The batch file exits immediately; the server keeps running in the background. Resolution order: venv Python → system pythonw.exe → system python.exe. Prints a clear error and pauses if Python or launcher.py is not found.

Option B — From CMD (shows startup messages in terminal)

CMD
py -3.13 "C:\AI-Server\server\launcher.py"

Useful during first setup to see any Python import errors printed to the terminal before the GUI appears.

Both options open the same GUI window (launcher.py). Here is what each panel does:

PanelWhat it does
AI Models — Active Model Shows the currently loaded Ollama model. Displays language confidence (e.g. ES: 99% nativo · EN: 99% native).
Switch to dropdown Lists all locally installed Ollama models. Select one and confirm to switch — no restart required while server is running.
Download dropdown + ⬇ Download Shows models not yet installed. Select a model and click Download to pull it via Ollama. Progress bar appears during download. Already-installed models are hidden from this list.
ℹ Info button Opens a popup with specs for all supported models — size, speed, language support, and recommendation tier.

First launch tip: Click Start Server, wait for the green Running indicator, then use the Download dropdown to get phi4-mini if you want better Q&A quality. The server stays on qwen3:1.7b until you switch.

CMD

All output goes to the console. Use this on machines without a display or when running as a background service.

Also open your browser and navigate to: https://localhost:5000/health

Known errors & fixes

🔴Error: tokenizers won't install — Python 3.14 not supported

Full message:

error output
error: the configured Python interpreter version (3.14) is newer than
PyO3's maximum supported version (3.13)
Failed building wheel for tokenizers

Cause: tokenizers (used by ChromaDB) is compiled in Rust using a library called PyO3. PyO3 v0.22.5 only supports up to Python 3.13. Python 3.14 is too new.

Fix: Install Python 3.13 and use it explicitly:

CMD — Administrator
winget install Python.Python.3.13 -e --accept-source-agreements --accept-package-agreements

Then use py -3.13 for all commands in this guide. You do not need to uninstall 3.14.

✅
Verify: py -3.13 --version → should show Python 3.13.x
🔴Error: building wheel for av failed — libavutil/mathematics.h not found

Full message:

error output
fatal error C1083: Cannot open include file: 'libavutil/mathematics.h': No such file or directory
Failed building wheel for av

Cause: faster-whisper==1.1.1 requires av<13 in its settings. Version av<13 has no ready-to-use file (wheel) for Python 3.13, so pip tries to compile it. That needs FFmpeg development files which are not installed on a normal Windows machine.

Fix: Follow the Python 3.13 special install order in Step 6. Key steps:

CMD
py -3.13 -m pip install "av>=13.0.0"
py -3.13 -m pip install faster-whisper==1.1.1 --no-deps
py -3.13 -m pip install ctranslate2 "huggingface_hub>=0.13" tokenizers
🔴Error: 'ollama' is not recognized as a command

Full message:

error output
"ollama" is not recognized as an internal or external command

Cause: Ollama was installed but its folder was not added to the Windows PATH. This sometimes happens with silent installs.

Fix — add Ollama to PATH permanently:

CMD — Administrator
setx PATH "%PATH%;%LOCALAPPDATA%\Programs\Ollama" /M

Then close CMD and open a new window. Try ollama list again.

⚠️
The /M flag sets the PATH for all users (system-wide). Without it the change only applies to the current user.
🟡Error: ollama serve — port 11434 already in use

Full message:

error output
Error: listen tcp 127.0.0.1:11434: bind: Only one usage of each socket address
(protocol/network address/port) is normally permitted.

Cause: Ollama is already running in the background. After installation, Ollama starts automatically with Windows. Running ollama serve again tries to use the same port — causing a conflict.

This is NOT an error — it means Ollama is working correctly. Check:

CMD
ollama list

If you see a table (even empty) → Ollama is running fine. You do not need to run ollama serve.

If you need to restart Ollama:

CMD — Administrator
taskkill /F /IM ollama.exe
ollama serve
🔴Error: faster_whisper not installed — audio unavailable

Full message in server logs:

server log
[WARN] Whisper initialization failed: No module named 'faster_whisper'
[WARN] Audio queries will be unavailable

Cause A: faster-whisper was not installed because it was excluded from requirements.txt (to avoid the av wheel problem). It must be installed separately.

Cause B: The install was done with Python 3.14, which doesn't support the package. See Error 1.

Fix — install manually with Python 3.13:

CMD
py -3.13 -m pip install "av>=13.0.0"
py -3.13 -m pip install faster-whisper==1.1.1 --no-deps
py -3.13 -m pip install ctranslate2 "huggingface_hub>=0.13" tokenizers

Restart the server after installing.

🟡Warning: ChromaDB telemetry errors in logs

Full message:

server log
Failed to send telemetry event: capture() takes 1 positional argument but 3 were given

Cause: Known bug in chromadb==0.5.x — there is an API mismatch in ChromaDB's own telemetry (usage reporting) module. It does not affect functionality.

Fix — silence the warning with the environment variable set in Step 3:

CMD — Administrator
setx ANONYMIZED_TELEMETRY False /M

Open a new CMD window, then restart the server. The warning will no longer appear.

🟡Warning: cryptography 45.0.0 is a yanked version

Full message:

pip output
WARNING: The candidate selected for download or install is a yanked version:
'cryptography' candidate (version 45.0.0)

Cause: Version 45.0.0 was removed (yanked) from PyPI after release due to a bug. Pip still installs it but shows this warning.

Fix: The install commands in Step 6 already use cryptography>=45.0.1 which avoids this. If you see the warning, run:

CMD
py -3.13 -m pip install "cryptography>=45.0.1"
🔴Error: 'python' is not recognized

Cause: Python was installed without the "Add to PATH" option, or you need to use py instead of python on Windows.

Fix A — use py instead of python:

CMD
py -3.13 --version

Fix B — add Python to PATH:

CMD — Administrator
setx PATH "%PATH%;%LOCALAPPDATA%\Programs\Python\Python313;%LOCALAPPDATA%\Programs\Python\Python313\Scripts" /M

Open a new CMD window after running this.

🔴Error: port 5000 already in use — server won't start

Cause: Another program is using port 5000 (could be another instance of the server, IIS, or another app).

Fix — find and stop the conflicting process:

CMD
# Find the PID (number in the last column)
netstat -ano | findstr :5000

# Stop that process (replace 1234 with the actual PID)
taskkill /F /PID 1234
🔴Error: pip install fails — SSL certificate verify failed

Cause: Old version of pip, corporate network with SSL inspection, or proxy.

Fix A — upgrade pip first:

CMD
py -3.13 -m pip install --upgrade pip

Fix B — retry with trusted host flags:

CMD
py -3.13 -m pip install flask --trusted-host pypi.org --trusted-host files.pythonhosted.org
🔴Error: browser shows SSL / certificate warning when opening server

Cause: The server uses a self-signed certificate. Browsers warn about any certificate not issued by a trusted authority. This is normal and expected — it is NOT a security problem.

Fix — bypass the browser warning:
On the warning page click Advanced → Proceed to [IP address] (unsafe). You only need to do this once per browser per machine.

Fix — force certificate regeneration (if IP changed and certificate is stale):

CMD
del "C:\AI-Server\server\server.crt"
del "C:\AI-Server\server\server.key"

Restart the server — new certificates are generated automatically.

Frequently Asked Questions

QDo I need internet after the installation is done?

No. Once everything is installed and the models are downloaded, the server runs 100% offline. No internet is required to use the RAG system, ask questions, or transcribe audio.

Internet is only needed during the initial installation to download Python packages, Ollama, and AI models.

QWhich Python version should I install?

Python 3.13 — it is the recommended version. All packages have precompiled files for it and it is the most recent version that works with the full stack.

Python 3.11 and 3.12 also work. Python 3.14 does NOT work (see Error 1 in Section 14).

QCan the server run without a dedicated GPU?

Yes. Both Ollama and Whisper fall back to CPU automatically. The server is fully functional without a GPU — responses will just be slower.

If you have an NVIDIA GPU, install the latest NVIDIA drivers. Ollama detects CUDA automatically and uses the GPU without any extra configuration.

QHow do I change the AI model the server uses?

Option A — GUI: Open the launcher, click the model selector dropdown, choose a model.

Option B — Edit the config file: Open C:\AI-Server\server\server_config.json in Notepad, change "current_model" to any model you have pulled (e.g. "qwen3:4b"), save and restart the server.

The model must already be downloaded with ollama pull <model-name> first.

QHow do I add PDF documents to the system?

Option A — GUI: Click "Upload PDF" in the launcher. The server indexes it automatically and shows progress.

Option B — Copy the file: Drop any .pdf file into C:\AI-Server\manuals\. The server picks it up on the next indexing cycle or after restart.

Large PDFs (hundreds of pages) may take 30–60 seconds to index fully.

QWhy does my browser show a security warning when I open the server?

The server uses a self-signed SSL certificate. Browsers flag any certificate that was not issued by a recognized authority. This is expected — it is not a problem.

How to proceed: on the warning page click Advanced → Proceed to [IP] (unsafe). You only do this once per browser. For Meta Quest headsets, accept the same way in the Quest browser.

QCan other devices (Meta Quest, phones, other PCs) connect to the server?

Yes — any device on the same Wi-Fi or LAN network can connect. Use the server machine's local IP address.

Find your IP:

CMD
ipconfig | findstr IPv4

Then connect from any device: https://192.168.x.x:5000

Requirements: firewall port 5000 must be open (Step 8), and both devices on the same network.

QHow do I check if the server is running correctly?
CMD
# Check if port 5000 is open
netstat -ano | findstr :5000

Or open your browser and go to https://localhost:5000/status — a JSON response confirms the server is up.

QHow do I reset the RAG database (start fresh with new documents)?

Stop the server first. Then delete the ChromaDB folder:

CMD
rmdir /S /Q "%LOCALAPPDATA%\TRAINING AI SERVER\chroma_db"

Restart the server. The folder is recreated empty. Re-upload your PDFs.

QThe server is slow. How can I speed it up?

1. Use a smaller model: qwen3:1.7b is the fastest available model — switch to it from the launcher if speed is more important than accuracy.

2. Add Defender exclusions (Step 8) — Defender scanning ChromaDB files on every read causes major slowdowns.

3. Use a GPU: Install NVIDIA drivers. Ollama auto-detects CUDA and offloads computation to the GPU.

4. Close unused browser tabs and apps to free up RAM.

QHow do I uninstall everything completely?
CMD — Administrator
# Stop processes
taskkill /F /IM python.exe /IM ollama.exe 2>nul

# Remove firewall rule
netsh advfirewall firewall delete rule name="TRAINING AI SERVER"

# Remove server files
rmdir /S /Q "C:\AI-Server"
rmdir /S /Q "%LOCALAPPDATA%\TRAINING AI SERVER"

# Remove Ollama models (optional — large files)
rmdir /S /Q "%USERPROFILE%\.ollama"

# Uninstall Python and Ollama
winget uninstall Python.Python.3.13
winget uninstall Ollama.Ollama
QWhat languages does the server support?

The server is fully bilingual Spanish (ES) and English (EN). The RAG retrieval, LLM responses, and Whisper speech recognition all work in either language. Whisper auto-detects the language of audio (Spanish primary). You can mix languages in the same session.
