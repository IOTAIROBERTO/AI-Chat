02

Back up what you want to keep

The uninstaller removes the ChromaDB database and all configuration. If you plan to reinstall later, back up these items first:

Option A — Back up the vector database (saves re-indexing time)

The ChromaDB folder contains all indexed document chunks. Copying it means you will not need to re-index PDFs after reinstalling.

CMD — Administrator
# Copy the ChromaDB to a safe location (e.g. your Desktop)
xcopy "%LOCALAPPDATA%\TRAINING AI SERVER\chroma_db" "%USERPROFILE%\Desktop\chroma_db_backup" /E /I /H /Y

Option B — Note which PDFs are indexed

Open the launcher and take a screenshot of the Indexed Manuals list, or run this command to see the indexed document names logged by the server:

CMD
type "%ProgramFiles%\TRAINING AI SERVER\logs\install.log" | findstr /i "index"
💡
Your original PDF files are never deleted. The uninstaller only removes the server's indexed copy (the vector database). Your source PDF documents remain wherever you originally stored them.
🔐
Open an Administrator command prompt before starting.
Press Win, type cmd, right-click Command Prompt, select Run as administrator.

Step 1 · Stop all running processes

The server, launcher, and Ollama must be stopped before any files can be deleted. Run these commands to force-stop them all.

CMD — Administrator
# Stop the Python launcher (GUI window)
taskkill /F /IM python.exe /FI "WINDOWTITLE eq *launcher*" >nul 2>&1

# Stop the Flask server process
taskkill /F /IM python.exe /FI "WINDOWTITLE eq *offline_server*" >nul 2>&1

# Stop the background launcher (no window)
taskkill /F /IM pythonw.exe >nul 2>&1

# Stop Ollama
taskkill /F /IM ollama.exe >nul 2>&1

# Verify nothing is still running on port 5000
netstat -ano | findstr :5000
✅ Verify — no output from the last command means port 5000 is free.

If you still see a line with :5000, note the PID in the last column and run: taskkill /F /PID <PID>

05

Step 2 · Remove Ollama AI models

Ollama models are large files (1–5 GB each). Remove them to reclaim disk space. This step is optional if you plan to use Ollama with other applications.

See what is installed

CMD
ollama list

Remove specific models

CMD
# Remove each model you no longer need
ollama rm qwen3:1.7b
ollama rm phi4-mini
ollama rm qwen3:4b
ollama rm qwen3:8b

Remove all models at once (PowerShell)

PowerShell — Administrator
ollama list | Select-Object -Skip 1 | ForEach-Object {
    $model = ($_ -split '\s+')[0]
    if ($model) { ollama rm $model }
}
✅ Verify — run ollama list again. Output should be empty (only the header row).
💡
Models are stored in %USERPROFILE%\.ollama\models\
If ollama rm fails (Ollama not in PATH), you can delete that folder directly using File Explorer.
06

Step 3 · Delete application files

This removes the main installation folder — server Python files, launcher, installer scripts, SSL certificates, and logs.

Standard installation path

CMD — Administrator
# Remove the main installation directory
rd /s /q "%ProgramFiles%\TRAINING AI SERVER"

# Also remove the local app data subfolder
rd /s /q "%LOCALAPPDATA%\TRAINING AI SERVER"
✅ Verify — both folders should be gone:
CMD
if exist "%ProgramFiles%\TRAINING AI SERVER" (echo STILL EXISTS) else (echo OK - deleted)
if exist "%LOCALAPPDATA%\TRAINING AI SERVER" (echo STILL EXISTS) else (echo OK - deleted)

If deletion fails (files locked)

A file may be held open by Windows Defender or another process. Use takeown to force deletion:

CMD — Administrator
takeown /f "%ProgramFiles%\TRAINING AI SERVER" /r /d y
icacls "%ProgramFiles%\TRAINING AI SERVER" /grant administrators:F /t
rd /s /q "%ProgramFiles%\TRAINING AI SERVER"
⚠️
If the folder still cannot be deleted — reboot and try again. Alternatively, use Task Manager to find and close any process with that path open.

Step 4 · Delete user data & vector database

The ChromaDB vector database and Ollama model data live separately from the application folder. Delete these to fully reclaim disk space.

⚠️
The ChromaDB folder contains all your indexed documents. Once deleted, every PDF will need to be re-indexed after reinstalling. Back it up first if needed (Section 02).
CMD — Administrator
# ChromaDB — the vector database (all indexed document chunks)
rd /s /q "%LOCALAPPDATA%\TRAINING AI SERVER\chroma_db" 2>nul

# Ollama model files (large — 1–5 GB per model)
rd /s /q "%USERPROFILE%\.ollama" 2>nul

# App data folder (any remaining config or temp files)
rd /s /q "%APPDATA%\VR Training AI Server" 2>nul
rd /s /q "%LOCALAPPDATA%\VR Training AI Server" 2>nul

Step 6 · Remove firewall rules

The installer added inbound and outbound firewall rules for port 5000. Remove them so the port is no longer exposed.

CMD — Administrator
# Remove all firewall rule names used by the server
netsh advfirewall firewall delete rule name="VR Manual Server"      2>nul
netsh advfirewall firewall delete rule name="VR Manual Server Out"  2>nul
netsh advfirewall firewall delete rule name="TRAINING AI SERVER"    2>nul
netsh advfirewall firewall delete rule name="TRAINING AI SERVER In" 2>nul
✅ Verify — none of these should return results:
CMD
netsh advfirewall firewall show rule name="VR Manual Server"
netsh advfirewall firewall show rule name="TRAINING AI SERVER"

Both commands should print "No rules match the specified criteria".

10

Step 7 · Remove registry entries

CMD — Administrator
# Machine-wide application key
reg delete "HKLM\SOFTWARE\VR Training AI Server" /f 2>nul

# Uninstall registry key
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\VR Training AI Server" /f 2>nul

# Per-user key
reg delete "HKCU\SOFTWARE\VR Training AI Server" /f 2>nul
💡
The 2>nul suffix suppresses "key not found" errors — it is safe to run all lines even if the keys do not exist.

Step 8 · Uninstall Ollama (optional)

⚠️
Ollama is shared software. Only uninstall it if you are certain no other applications on this machine use it. If unsure, skip this step.

Method 1 — winget (recommended)

CMD — Administrator
winget uninstall Ollama.Ollama --silent

Method 2 — Control Panel

Press Win + R → appwiz.cpl → find Ollama → Uninstall.

Method 3 — Manual removal (if uninstaller is missing)

CMD — Administrator
# Find where Ollama is installed
where ollama.exe

# Delete the Ollama directory (adjust path from above output)
rd /s /q "%LOCALAPPDATA%\Programs\Ollama"

# Remove Ollama from PATH (PowerShell)
[System.Environment]::SetEnvironmentVariable("PATH",
  [System.Environment]::GetEnvironmentVariable("PATH","User") -replace ";?[^;]*ollama[^;]*","",
  "User")
✅ Verify — close and reopen CMD, then:
CMD
ollama --version

Should print "'ollama' is not recognized" if fully removed.

Step 9 · Uninstall Python (optional)

⚠️
Python is shared. Many Windows tools, scripts, and IDEs depend on Python. Only uninstall if you are certain nothing else on this machine needs it.

Method 1 — Control Panel

Press Win + R → appwiz.cpl → find Python 3.x → Uninstall.

Method 2 — winget

CMD — Administrator
# List installed Python versions
winget list --name Python

# Uninstall (adjust version number)
winget uninstall Python.Python.3.13 --silent
💡
Python packages (pip installs) are removed automatically when Python is uninstalled. You do not need to manually delete the site-packages folder.

Verify complete removal

Run this checklist after all steps to confirm a clean uninstall.

CMD — Administrator
# 1. Application folder gone?
if exist "%ProgramFiles%\TRAINING AI SERVER" (echo [FAIL] App folder still exists) else (echo [OK]   App folder deleted)

# 2. Local app data gone?
if exist "%LOCALAPPDATA%\TRAINING AI SERVER" (echo [FAIL] Local data still exists) else (echo [OK]   Local data deleted)

# 3. ChromaDB gone?
if exist "%LOCALAPPDATA%\TRAINING AI SERVER\chroma_db" (echo [FAIL] ChromaDB still exists) else (echo [OK]   ChromaDB deleted)

# 4. Port 5000 no longer listening?
netstat -ano | findstr :5000 >nul && echo [FAIL] Port 5000 still in use || echo [OK]   Port 5000 free

# 5. Firewall rules removed?
netsh advfirewall firewall show rule name="TRAINING AI SERVER" >nul 2>&1 && echo [FAIL] Firewall rule still exists || echo [OK]   Firewall rules removed

# 6. Registry key gone?
reg query "HKLM\SOFTWARE\VR Training AI Server" >nul 2>&1 && echo [FAIL] Registry key still present || echo [OK]   Registry key deleted

All lines should print [OK]. For any [FAIL] line, return to the corresponding step above and repeat.

Frequently Asked Questions

QCan I reinstall the server after uninstalling?

Yes. Follow the TRAINING_AI_SERVER_Manual.html installation steps again at any time to reinstall all components from scratch.

If you backed up the ChromaDB folder (Section 02), copy it back to %LOCALAPPDATA%\TRAINING AI SERVER\chroma_db\ after reinstalling to restore all indexed documents without re-indexing.

QCan I keep the Ollama models so I don't re-download them?

Yes. Skip Step 2 (Remove Ollama AI models) and Step 8 (Uninstall Ollama). Ollama and its models will remain on your machine.

When you reinstall the server, it detects the existing Ollama installation and skips the download steps. The launcher will show the existing models in the Switch to dropdown immediately after reinstall.

QSome files are still there after the deletion commands — why?

A file may be locked by another process — typically Windows Defender scanning the ChromaDB folder, or a Python/Ollama process that didn't fully stop.

Fix A: Reboot the machine and retry the rd command. Most locked files release after reboot.

Fix B: Use the takeown approach documented in Step 3 to force ownership and delete.

QMy PDF files were in the manuals folder — are they gone?

The manuals\ subfolder inside the installation directory is removed as part of Step 3. If you stored your original PDFs there, they are gone.

The server design expects you to keep your PDFs in a separate location (e.g. your Documents folder) and index them from there. The server only stores the extracted vector chunks in ChromaDB — not the PDFs themselves.

QI only want to uninstall and reinstall cleanly — what is the minimum I need to do?

For a clean reinstall keeping your Ollama models (to avoid re-downloading):

  1. Run Steps 1, 3, 4 (skip Ollama models), 5, 6, 7.
  2. Skip Steps 2, 8, 9 — keep Ollama and Python.
  3. Follow the installation manual again from Step 5.

Total time: about 5 minutes (no re-downloading).

QHow do I check whether the server is completely gone?

Run the verification block in Section 13 — all lines should print [OK]. Also check:

  • Task Manager → no python.exe or ollama.exe processes (unless you kept Ollama).
  • Start Menu → no TRAINING AI SERVER folder.
  • Control Panel → Programs → no TRAINING AI SERVER entry.
